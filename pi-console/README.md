# pi-console

研究室の Raspberry Pi（`raspi@ddse.local`）をブラウザから操作するコンソール。ブラウザ → `server.mjs` → SSH → Pi の順にコマンドが流れる。

## 使い方

必要なもの: Node.js 22 以上、Pi に SSH で入れること（パスフレーズ付きの鍵は `ssh-add` で ssh-agent に入れておく）。

```sh
cd pi-console
cp .env.example .env   # PI_HOST を確認（研究室なら raspi@ddse.local）
npm run dev            # Windows は npm start して http://127.0.0.1:8765 を開く
```

ヘッダーの丸が緑ならつながっている。止めるときは `Ctrl+C`（Pi で動いているモードは止まらない）。

## モード

Pi のディスプレイに出すものを切り替える。動くのは 1 つだけで、押すとほかは止まる。

| ボタン     | Pi のディスプレイ                                                                          |
| ---------- | ------------------------------------------------------------------------------------------ |
| 目         | ドットの目がまばたきする（カメラなし）                                                     |
| デフォルト | 全部止めてログイン画面                                                                     |
| 見守り     | 両手ピースを 3 秒で撮影し、出席 Bot（`lab-attendance`）経由で Slack に投稿。起動に約 30 秒 |

「目」「見守り」は Pi の `~/hand-landmarker/` にある `pi_eyes.py`・`pi_peace.py` を起動する。

## 注意

- `127.0.0.1` だけで待ち受ける。Pi の再起動・電源オフができるので外に公開しない
- 写真・`.env` はコミットしない（人が写る、公開リポジトリ）
- `raspi` は全員共有。ほかの人がモードを動かしていないか見てから押す
- オフラインになったら、まずターミナルで `ssh raspi@ddse.local` が通るか確かめる
